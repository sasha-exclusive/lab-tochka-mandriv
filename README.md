# Точка мандрів (Travel Budget Planner)

Це лабораторна робота #1 з курсу «Технології створення програмних продуктів».

Веб-додаток допомагає планувати бюджет подорожей:
- створення подорожей з назвою, датами та країною;
- додавання витрат (транспорт, житло, харчування);
- перегляд статистики витрат у вигляді списку та діаграми.

## Структура репозиторію

- `TЗ.md` — технічне завдання
- `VERSIONING.md` — політика версіонування
- `RELEASE_TEMPLATE.md` — шаблон release notes
- `CHANGELOG.md` — історія змін
- `ACCEPTANCE_CHECKLIST.md` — чекліст приймання
- `README.md` — цей файл
- `REPORT_SHORT.md` — короткий звіт про виконану лабораторну

## Версії

- **v1.0.0** — початковий реліз з повним ТЗ і шаблонами.

## Інструкції запуску (демонстрація)

1. Відкрити репозиторій у VS Code.
2. Переглянути Markdown-файли.
3. (Опційно) Запустити простий React-додаток локально через `npm start`.
